# Phishing Awareness Training

## Cyber Security Internship - CodeAlpha

### Project Overview

This project is a phishing awareness training module designed to educate users about phishing attacks, social engineering techniques, and how to protect against online threats.

## Objectives

- Understand phishing attacks
- Identify phishing emails and fake websites
- Learn common social engineering techniques
- Apply best practices to stay safe online

## Topics Covered

- What is Phishing?
- Types of Phishing Attacks
- Phishing Email Detection
- Fake Website Identification
- Social Engineering Techniques
- Prevention Methods

## Tools Used

- Microsoft PowerPoint / LibreOffice Impress
- Markdown
